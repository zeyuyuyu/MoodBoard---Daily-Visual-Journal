# MoodBoard
A delightful daily visual journal that helps users track their mood through colors, patterns and music. Users select colors and patterns that match their feelings each day, building a beautiful interactive calendar of their emotional journey. The app generates soothing background music based on their selections.

Features:
- Interactive color/pattern picker
- Daily mood tracking
- Musical accompaniment that matches mood
- Monthly view of mood patterns
- Share mood patterns with friends

Tech Stack:
- HTML5 Canvas for visualization
- Web Audio API for procedural music
- LocalStorage for data persistence
- Vanilla JS for interactivity
